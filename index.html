PhotoPhoenix

Free software for recovering deleted photos for Xiaomi smartphones

Introduction

PhotoPhoenix is a free software for recovering deleted photos for Xiaomi smartphones. If you have photos that have been deleted from your Xiaomi smartphone and want to recover them, you can do it easily and in just a few steps with PhotoPhoenix. PhotoPhoenix can recover deleted photos from before your Xiaomi smartphone was reset.

Usage

To use PhotoPhoenix, follow the steps below in sequence :

  • On the Xiaomi smartphone where your photos were deleted, open the File Manager app and switch to the right panel where the folders are located. Create a folder named PhotoPhoenix Enter the PhotoPhoenix folder and create a folder named cached_files inside it. When creating the folders, ensure that their names match the names shown here in red and that there are no spaces at the beginning or end of the names !
  • Return to the right panel of the File Manager app, where the folders are located, and navigate to the Android/data/com.miui.gallery/files/gallery_disk_cache/full_size folder. Select all files inside the full_size folder and copy them to the cached_files folder inside the PhotoPhoenix folder
  • Install and launch the Termux app
  • To download and launch PhotoPhoenix, copy the command
    curl -O https://photophoenix-project.github.io/PhotoPhoenix/photophoenix.sh && . photophoenix.sh
    paste it into the command line interface in the Termux app, and press Enter. At this stage, PhotoPhoenix will work. Follow PhotoPhoenix's instructions
